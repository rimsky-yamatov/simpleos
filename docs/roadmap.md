# SimpleOS 実装ロードマップ

## 0. ここまでの進捗
- Rust ワークスペースを用意した
- emulator と kernel の雛形を作成した
- BASIC REPL の最小実装を入れた
- 行番号付きプログラムの保存/読み込みの概念を追加した
- ファイルシステムの保存先ディレクトリを用意した

## 1. エミュレータ段階（最優先）
- BASIC に行番号付きプログラム管理を導入する
- RUN / LIST / LOAD / SAVE / DIR / NEW を完成させる
- FOR / NEXT / IF THEN / GOTO を追加する
- 配列や文字列を段階的にサポートする
- サンプルプログラムを `emulator/examples` に置く

## 2. カーネル段階
- `kernel` を no_std の最小カーネルとして整理する
- VGA 出力、キーボード入力、割り込みの抽象化を追加する
- BASIC インタプリタの内部表現をカーネル側に移植できるように分離する

## 3. ファイルシステム
- 仮想ツリー型のディレクトリ構造を実装する
- BASIC から `SAVE` / `LOAD` / `DIR` を扱えるようにする
- それをカーネルの初期イメージに埋め込む設計を考える

## 4. ISO 化
- GRUB を使った起動イメージを作る
- qemu で起動確認する
- `iso/` もしくは `dist/` 配下に成果物を出力する

## 5. 最終目標
- 古典的な BASIC を内蔵した、ブート可能な簡易OSを動かす
- ファイル保存やディレクトリ運用ができる
- qemu 上で起動し、BASIC の REPL が現れる
